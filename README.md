# IT Museum

Веб-квест для в стиле терминала. Нужно пройти 10 испытаний, посвящённых великим учёным в истории информатики.

## Стек

- **Frontend**: React 18 
- **Backend**: Express
- **БД**: SQLite (sql.js)

## Запуск 

```bash
npm install
npm run dev
```

Фронтенд: http://localhost:3000  
Бэкенд: http://localhost:3002
